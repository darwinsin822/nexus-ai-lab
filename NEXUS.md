# NEXUS AI LAB 2.0 — COMPENDIO TÉCNICO

## Visión General
Nexus AI Lab unifica el ecosistema de IA para desarrollo local en Linux Mint / Ubuntu, operando como router, gestor de tareas, capa de seguridad y puente entre modelos propietarios de alta capacidad y herramientas open-source.

## Comandos CLI Soportados

| Comando | Descripción |
| :--- | :--- |
| `nexus init` | Inicializa `.nexus/` en el proyecto actual |
| `nexus doctor` | Diagnóstico de salud y dependencias |
| `nexus status` | Estado de motores, Git y tareas activas |
| `nexus agents` | Listado dinámico de perfiles y agentes |
| `nexus models` | Catálogo de modelos con desglose de costes |
| `nexus providers` | Proveedores y credenciales configuradas |
| `nexus tasks` | Listado y estados de tareas persistentes |
| `nexus run "<prompt>"` | Ejecución inteligente con auto-routing |
| `nexus plan "<prompt>"` | Generación de anteproyecto arquitectónico |
| `nexus hybrid "<prompt>"` | Pipeline completo híbrido (Plan -> Codifica -> Prueba -> Revisa) |
| `nexus handoff` | Visualización del documento de transferencia de contexto activo |
| `nexus dashboard` | Panel visual interactivo de terminal |
| `nexus memory [file]` | Consulta y mantenimiento de la memoria de proyecto |
| `nexus skills` | Catálogo unificado de skills disponibles |
| `nexus history` | Telemetría, tiempos y reporte de ahorro de recursos |
